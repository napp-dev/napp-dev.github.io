1. 自動更新を設定する

Weekwallの「自動更新」を開き、案内に従ってください。Weekwall: Set Wallpaperをインストールし、動作確認を実行して求められた操作を許可します。Appleの「ショートカット」で「時刻」のオートメーションを毎日実行するように作成し、「すぐに実行」を選び、Weekwall: Set Wallpaperを選択します。ショートカットの名前は変更しないでください。更新時刻は自由に選べます。

2. 壁紙が古い、または適用できない

Weekwallを開き、壁紙を手動で適用してみてください。カレンダーの許可、選択したカレンダー、ショートカット、オートメーションを確認します。提供されたショートカットを「すぐに実行」する設定が必要です。失敗する場合はWeekwallからショートカットを再追加し、オートメーションでも選び直してください。壁紙を「写真」に保存し、手動で設定することもできます。無料期間終了後の自動更新にはProが必要です。

3. 予定が表示されない・アクセス許可

WeekwallはAppleの「カレンダー」で利用できるカレンダーの予定を読み取ります。そちらに予定が表示され、Weekwallで正しいカレンダーを選んでいるか確認してください。iOSの設定でカレンダーへのアクセスを許可します。写真ピッカーが共有するのは選択した画像だけです。生成した壁紙の保存には、写真の追加許可が必要です。通知は任意です。

4. 個人的な予定のタイトルを隠す

Weekwallの「設定 → 予定のプライバシー → タイトルを非表示」を選び、壁紙を再生成して適用してください。時刻は引き続き表示されます。保存済みの画像や現在のロック画面は、置き換えるまで変わりません。

5. Proの復元・解約・返金

Proを購入したApple Accountで、Weekwallの「設定 → 購入を復元」を使用してください。通信状態と購入状況を確認します。サブスクリプションはiOSの「設定 → 自分の名前 → サブスクリプション」で管理できます。Appleの解約手順をご覧ください。Weekwallを削除しても解約されません。返金はAppleがreportaproblem.apple.comで処理します。買い切り購入に継続的な支払いはありません。

6. 言語、ローカルデータ、プライバシー

Weekwallの言語はiOSのアプリ設定で選べます。アプリを削除すると端末内の背景や設定が失われる場合がありますが、元の予定、保存した写真、オートメーションは削除されません。個人データに関するご依頼はサポートにメールしてください。プライバシーポリシーと利用規約もご覧ください。
