# 지원

[{{contact_email}}](mailto:{{contact_email}})으로 이메일을 보내 주세요. iPhone 모델, iOS 및 앱 버전, 발생한 문제와 기대한 결과를 알려 주세요. 스크린샷에서 비공개 캘린더 정보를 가려 주세요. 암호나 카드 정보를 보내지 마세요.

## 1. 자동 업데이트 설정

Weekwall의 자동 업데이트를 열고 안내를 따르세요. Weekwall: Set Wallpaper를 설치하고 확인을 실행한 뒤 요청한 동작을 허용하세요. Apple 단축어에서 특정 시간에 매일 실행되는 자동화를 만들고 즉시 실행을 선택한 뒤 Weekwall: Set Wallpaper를 선택하세요. 단축어 이름은 바꾸지 마세요. 업데이트 시간은 원하는 대로 선택할 수 있습니다.

## 2. 배경화면이 오래되었거나 적용되지 않음

Weekwall을 열고 배경화면을 수동으로 적용해 보세요. 캘린더 권한, 선택한 캘린더, 단축어 및 자동화를 확인하세요. 자동화는 즉시 실행되며 제공된 단축어를 사용해야 합니다. 실패하면 Weekwall에서 단축어를 다시 추가하고 자동화에서도 다시 선택하세요. 배경화면을 사진 앱에 저장한 뒤 수동으로 설정할 수도 있습니다. 무료 기간이 끝나면 자동 업데이트에 Pro가 필요합니다.

## 3. 이벤트 누락 및 권한

Weekwall은 Apple 캘린더에서 이용할 수 있는 캘린더의 이벤트를 읽습니다. 캘린더 앱에 이벤트가 보이는지, Weekwall에서 올바른 캘린더를 선택했는지 확인하세요. iOS 설정에서 캘린더 접근을 허용하세요. 사진 선택기는 선택한 이미지만 공유하며 생성한 배경화면을 저장하려면 사진 추가 권한이 필요합니다. 알림은 선택 사항입니다.

## 4. 비공개 이벤트 제목 가리기

Weekwall에서 설정 → 이벤트 정보 보호 → 제목 가리기를 선택한 뒤 배경화면을 다시 생성하고 적용하세요. 시간은 계속 표시됩니다. 이미 저장한 이미지와 현재 잠금 화면은 교체하기 전까지 바뀌지 않습니다.

## 5. Pro 복원, 구독 취소 및 환불

Pro를 구입한 Apple 계정으로 Weekwall의 설정 → 구입 항목 복원을 사용하세요. 인터넷 연결과 구입 상태를 확인하세요. iOS 설정 → 사용자 이름 → 구독에서 구독을 관리하며 [Apple 취소 안내](https://support.apple.com/en-us/118428)를 참고할 수 있습니다. Weekwall을 삭제해도 구독은 취소되지 않습니다. 환불은 Apple이 [reportaproblem.apple.com](https://reportaproblem.apple.com/)에서 처리합니다. 일회성 구입에는 반복 결제가 없습니다.

## 6. 언어, 로컬 데이터 및 개인정보

iOS 앱 설정에서 Weekwall 언어를 선택하세요. 앱을 삭제하면 로컬 배경과 설정이 지워질 수 있지만 원본 이벤트, 저장한 사진 및 자동화는 삭제되지 않습니다. 개인정보 관련 요청은 지원팀에 보내 주세요. [개인정보 처리방침](../privacy/)과 [이용약관](../terms/)을 확인하세요.
