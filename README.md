# Napp

Приложения Napp, политики конфиденциальности, условия использования и поддержка.

[Перейти на сайт](https://napp-dev.github.io/)

Страницы генерируются из `apps/*/app.json` и документов в `content/`.
Поле `catalogue` в метаданных приложения задаёт название, краткое описание
и подпись превью на главной. Общий дизайн находится в `assets/style.css`.

После изменений пересоберите страницы и проверьте ссылки:

```sh
python3 scripts/build_pages.py
python3 scripts/build_pages.py --check
```
